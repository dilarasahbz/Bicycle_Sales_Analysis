# Bicycle Company Sales Analysis — Power BI Dashboard

A project developed by a team of 3 as part of the Business Intelligence course. An interactive dashboard was built using Microsoft Power BI by analyzing a bicycle company dataset provided by the course instructor.

## Project Content

The dashboard consists of 4 pages:

### 1. Home
Overall performance summary — total sales, sales volume (units sold), revenue per employee, regional sales map, actual vs. target sales gauge indicator, gross profit distribution by product category, top-selling product, profit, and average daily sales amount.

### 2. Sales
Sales trends over the years — year-to-date (YTD) total sales, average order value by year, monthly sales comparison, sales distribution by region, and daily average sales change compared to the previous year.

### 3. Product
Product-level analysis — category breakdown, order count by product, product distribution by gross profit / profit margin / sales volume (scatter chart), average items per sale, and top-selling color.

### 4. Personnel
Personnel performance analysis — sales shares of personnel, individual total sales amounts, average transaction value per sale by employee, variance ratio to annual sales target, and the number of personnel performing above the overall average.

Interactive analysis can be performed across all pages using the **Year** slicer.
